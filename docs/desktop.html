このアプリについて

これはChordiaというMacOS, WindowsOS用のアプリです。

アプリ内容についてですが、ご自身がお持ちのmp3ファイルを利用してお持ちの音楽を管理したり、YouTubeなどのプラットフォームから楽曲をダウンロードしつつ、プレイリストとしても機能するアプリとなっております。

おおよそオフラインでご利用いただけます。（Mobile版へ楽曲を同期する際にはインターネット環境が必要となります）
アプリ開発にはAIを利用しております。（アプリ本体にはAIを組み込んでおりません）

すぐ使いたいならここ読んで！（アプリの起動方法、使い方）

まずはあなたの環境に適したファイルを Releases よりダウンロードします。

Chordia_%version%_Windows.zip

Windows用のパッケージファイル。展開すると中に Chordia.exe が配置されており、楽曲データやプレイリストなどは同じディレクトリに保存されます。他のディレクトリを汚すことなく、展開したフォルダ内で完結します。

Chordia_%version%_Windows_x64_setup.exe

インストーラーです。対応言語：日本語、英語、中国語(簡体字/繁体字)、韓国語。
※ 現在、このインストール方法でインストールするとアプリを開けないというバグが発生しています。

Chordia_%version%_macos_portable.app

このファイル一つで完結するMacOS用のアプリケーションファイル。楽曲データやプレイリストなどはappファイルの中に保存され、他のディレクトリを汚しません。

Chordia_%version%_macos_aarch64.dmg

MacOS用のインストーラーファイル。実行するとApplicationsフォルダにドラッグ＆ドロップしてインストールする画面が表示されます。

ダウンロードファイル別の初期起動方法

Chordia_%version%_windows_portable.zip

zipファイルを展開し、中にある Chordia.exe を起動します。そのままご利用いただけます。

Chordia_%version%_windows_x64_setup.exe

ダウンロードしたファイルをダブルクリックしてインストーラーを起動します。
もし「WindowsによってPCが保護されました。」と表示されたら、アンダーラインの引かれている「詳細情報」をクリックして実行ボタンをクリックします。画面の指示に従ってアプリをインストールします。初期設定のままインストールすると、デスクトップにChordiaのショートカットが作成されます。次回以降はこれを使用してアプリを起動します。

Chordia_%version%_macos.zip

ダウンロードしたファイルをダブルクリックしてファイルを展開します。展開して作成されたappファイルを開きます。
※ この時、アプリを起動できない場合は、設定アプリ ＞ プライバシーとセキュリティの一番下のセキュリティの項目にある「このまま開く」というボタンをクリックすることで起動できます。（次回以降はダブルクリックで起動可能）
※ 「このまま開く」ボタンが存在しない場合、Command + Spaceで「ターミナル」と検索し、ターミナル.appを開きます。そこで以下を入力し、展開して作成されたappファイルをターミナルにドラッグ＆ドロップしてEnterキーを押します。

sudo xattr -rd com.apple.quarantine

（このコマンドは未署名、未公認アプリの隔離属性を削除するものです）
次回以降も同様にappファイルをダブルクリックして起動します。

Chordia_%version%_universal.dmg

ダウンロードしたファイルをダブルクリックしてインストーラーを起動します。
※ アプリを起動できない場合は、設定アプリ＞プライバシーとセキュリティの一番下のセキュリティの項目にある「このまま開く」をクリックします。
左にあるChordia.appという大きなアイコンを右のApplicationsフォルダにドラッグ＆ドロップすることでインストールできます。Command + SpaceでChordiaと入力して起動するか、Finderでアプリケーションを開きダブルクリックで起動します。
※ 起動できない場合で「このまま開く」が存在しない場合、ターミナルで以下コマンドを入力後、アプリケーションフォルダ内の Chordia.app をターミナルにドラッグ＆ドロップしてEnterキーを押してください。

sudo xattr -rd com.apple.quarantine

アプリの使用方法（クイックガイド）

「曲を追加」ではChordiaに曲を登録します。曲名、アーティスト、アルバムなどが設定できます。情報を入力して楽曲ファイルをアップロードしたら、「ライブラリに追加」をクリックします。

ここで追加した楽曲は「データベースを管理」の画面に表示されます。セルをダブルクリックして編集できます。試聴もできます。削除もここで可能です。

音楽をプレイリストに登録して楽しむには「音楽を再生」をクリックします。画面を開くと既存のプレイリストが読み込まれますが、初期状態では何も登録されていません。

「プレイリスト」という文字の下の何もない個所を右クリックすると、「プレイリストを新規作成」という項目が表示されます。これをクリックしてプレイリストを作成します。

プレイリストに曲を追加するには左の追加したいプレイリスト名を右クリックし、「曲を編集」をクリックします。ここで登録されている楽曲一覧が表示されるのでプレイリストに追加したい楽曲にチェックを入れて右下の「設定」をクリックします。

タイトル、アーティスト、アルバムなどカラムをクリックすることでソートできたり様々な機能がこの画面にはあります。詳細は下部の全機能説明をご確認ください。そしたらプレイリストをどれかクリックして右に表示された再生ボタンやシャッフルボタンを押してみましょう。プレイリストを再生できます。

ファイル構成と起動まで

「すぐ使いたいならここ読んで！」の通りにアプリを起動・設定を変更したり曲を追加すると、library フォルダと userfiles フォルダが生成されます。

  • MacOSの場合: .appファイルを右クリックし、「パッケージの内容を表示」をクリックし、Contents/MacOS/ 内に作成されます。
  • WindowsOS ポータブル版(.zip): 展開したフォルダの中の Chordia.exe と同じディレクトリに作成されます。
  • WindowsOS setup.exe: %userfiles%/AppData/Local/Chordia/ に作成されます。

生成されるディレクトリ詳細:

  • library/ : images フォルダ, music フォルダが生成されます。
  • userfiles/ : settings.ini（アプリ内設定）, history.json（再生履歴）, lyric.json（歌詞）, music.json（楽曲情報）, played_times.json（再生回数）, playlist.json（プレイリスト＆スマートプレイリスト設定）, tool_versions.json（拡張機能バージョン）, bin/（拡張機能アプリ保存先）, playlist/（通常プレイリスト楽曲一覧）が生成されます。

※ 基本的に library フォルダや userfiles フォルダには手を加えないことを推奨します。（拡張機能にバグが発生したら library/bin を削除すると修正されることがあります）
また、ディレクトリ構造は変更しないでください（まとめて移動する場合は問題ありません）。

全機能説明

1. 曲を追加

1曲追加

曲名、アーティスト、アルバム、ジャンル、トラックナンバー、アルバムアートが設定できます。曲名やアーティスト等は過去の入力候補から選択可能です。楽曲はローカルアップロードのほか、動画プラットフォームからのダウンロードにも対応（※拡張機能の導入が必要）。カバーアートは動画サムネイル・ローカル画像・画像URLから指定できます。LRCLIB APIを利用した歌詞の自動取得にも対応。「ライブラリに追加」をクリック時、既存の曲と重複している場合は確認プロンプトが表示されます。

YouTube再生リストから一括追加

「曲を追加」画面の上部タブを切り替えます。再生リストのURLを入力して右のボタンをクリックすると解析処理が始まり動画一覧が表示されます。テーブルで曲情報を調整後、ライブラリに追加できます。

json, csvによるインポート

楽曲情報を持ったJSON/CSVファイルを選択（ドラッグ＆ドロップ可）します。読み込まれた楽曲一覧を確認・編集の上、インポートを完了させます。（フォーマット詳細はREADME末尾参照）

ZIPによるインポート

インポート画面のタブを切り替え、mp3ファイルをまとめたZIPファイルを選択（ドラッグ＆ドロップ可）。サブディレクトリ内のmp3もすべて自動読み込みされます。

2. データベースを管理

登録された全楽曲が一覧表示されます（初期設定1ページ50曲表示、設定で変更可能）。

  • シンプルな検索: 上部検索ボックスでキーワード検索ができます。ページ移動しても結果は維持されます。
  • 高度な検索: 右上の「高度な検索」ボタンから、複数条件を指定した高度な絞り込みが可能です。

3. データの引継ぎ

引き継ぎたいデータを選択してエクスポートし、引継ぎ画面下の「データのインポート」で取り込みます。バージョン間の互換性はリリースノートをご確認ください。

4. 音楽を再生

プレイリストの作成や登録楽曲の再生を行うメイン画面です。

  • 画面左側: プレイリスト、アルバム、アーティスト表示を切り替え可能。アルバム・アーティストは自動で再生リストが生成されます。
  • プレイリストの作成・編集: 左側の空きスペースを右クリックで新規作成。右クリックメニューから名前の編集、削除、曲の編集（チェックボックスで選択・設定）が行えます。Shiftキーを押しながらクリックすると範囲一括選択が可能です。カラム名クリックでソート、検索ボックスでタグ絞り込みが可能です。
  • スマートプレイリスト: 条件に合致する楽曲が自動で追加される動的プレイリスト。「スマートプレイリストを作成」から設定できます。「ルールを編集」から後から条件を変更することも可能です。
  • ミニプレイヤー: 再生中に上部カバーアートをクリックすると起動します。
  • キュー・歌詞: 上部の三点マークをクリックすると、次に再生される曲の一覧（キュー）や事前登録した歌詞を表示できます。
  • 音量変更 / 履歴記録: 左上の音量バーで調整可能。本画面からの再生は履歴と再生回数に記録されます。

5. Mobile版に同期

新しいウィンドウが開き、PCのローカルIPアドレスが表示されます。（※相互のバージョン互換性は 互換性情報 をご確認ください）

IPアドレスと認証コードによる接続

Mobile版の「同期」タブで手動接続を選択し、Desktop版に表示されたIPアドレスとポート番号を入力。「PCに接続要求」をタップ後、Desktop版側で許可をクリックし、表示された認証コードをMobile版に入力します。

QRコードによる接続

Mobile版で「QRコードで自動接続」をタップし、Desktop版の「QRコードを表示」をスキャンします。Desktop版で接続リクエストを許可すれば接続完了です。

WAN内の同期（外出先同期）

Cloudflare Quick Tunnels を使用し、PCとスマホが異なるネットワークにいる状態でも安全に同期できます。Desktop版で「外出先(WAN)接続モード」をONにし、「緑色：有効・待機中」になるのを待ちます。表示された「WAN パブリック URL」またはQRコードをMobile版の「WAN(外出先/HTTPS)」タブで読み取り、表示される認証コードを入力して接続します。

接続後の同期操作

接続後、Mobile版で同期したいプレイリストを選択します。「効率同期（既存曲を流用）」または「削除して同期（一度全削除して再同期）」を選択可能です。

6. 拡張機能・設定・情報

  • 拡張機能: 動画プラットフォームからの楽曲取り込みや、WAN同期（Cloudflared）に必要なツールをダウンロード・管理します。
  • 設定（一定音量機能）: LUFS（人間が感じる騒がしさの指標）を元に楽曲間の音量差を最小限に抑える機能（要 ffmpeg 拡張機能）。
  • 情報: ライセンス表記とバージョン情報を確認できます。
