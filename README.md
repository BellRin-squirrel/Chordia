# Chordia (音楽管理・再生アプリ)

Chordia（コーディア）は、ローカルの音楽ファイル（mp3）の管理・再生および動画プラットフォームからのダウンロードに対応したクロスプラットフォーム音楽アプリです。

おおよそオフラインでご利用いただけます（楽曲を同期・ダウンロードする際にはインターネット環境が必要です）。  
アプリ開発にはAIを利用しております。

---

## 💻 対応プラットフォーム
- **Desktop版**: Windows / macOS
- **Mobile版**: iOS / iPadOS / Android (準備中)

---

## ⚡ クイックスタート

### Desktop版
1. [Releases](https://github.com/BellRin-squirrel/Chordia/releases) より環境に応じたファイルをダウンロードします。
2. 展開またはインストール後、アプリを起動します。
3. 「曲を追加」より楽曲を登録し、「音楽を再生」からプレイリストを作成して音楽を再生できます。

### Mobile版
1. パソコン（Sideloadly等）経由でipaファイルをインストールします。
2. Desktop版とMobile版を起動し、QRコードまたはIPアドレス認証を用いて接続・同期を行います。
